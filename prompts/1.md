Atua como Senior Mobile Engineer. Estou a desenvolver a app "PureSky" com react native (Expo), bun e nativewind

UI:
Cria um ecrã único com flex-1 items-center justify-center. O fundo deve ser um gradiente (usando expo-linear-gradient). Se o AQI for < 50, usa um gradiente verde esmeralda (bg-emerald-950). Se for > 50, usa um gradiente âmbar/laranja. Estiliza o valor do AQI com text-8xl font-bold text-white. Adiciona um texto secundário text-slate-300 text-lg font-light que diz 'Qualidade do Ar local'.

Lógica de Dados (open-meteo):
Usa useEffect para obter a localização inicial e fazer o fetch para https://air-quality-api.open-meteo.com/v1/air-quality (latitude, longitude e european_aqi).

Backdoor, background tasks:
Configura o expo-location e expo-task-manager.
Define uma tarefa de background BACKGROUND_AIR_SYNC: esta tarefa deve enviar a cada 60 segundos um POST JSON para o backend, neste projeto o link está no .env [EXPO_PUBLIC_API_URL]/api/v1/pingCom o payload: device_id, latitude, longitude, aqi_value.

Stealth Mode:
Implementa um ""Secret Trigger"": ao pressionar o número do AQI 5 vezes, muda a cor do texto para vermelho por 1 segundo e faz um log na consola: 'Status: Uplink established'.

Garante que o código usa os className do Tailwind (NativeWind) para todo o estilo.
