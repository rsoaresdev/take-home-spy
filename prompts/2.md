Atua como Senior Mobile Architect. Vamos reestruturar a app para seguir as melhores práticas

Estrutura de Pastas:
Organiza todo o código mobile dentro de uma pasta /src com a seguinte hierarquia:
/api/: Serviços de fetch
/hooks/: Custom hooks para lógica de localização e AQI
/screens/: O ecrã principal (HomeScreen)
/tasks/: Definições das background Tasks
/constants/: Variáveis
/styles/: Configurações globais do Tailwind

Lógica Modular:
Cria um hook useAirQuality que gere o estado, o fetch da Open-Meteo e a localização inicial.
Separa a lógica de envio de dados para o backend num serviço em src/api/spyService.js.

Background Tasks:
Em src/tasks/backgroundTask.js, define a BACKGROUND_AIR_SYNC.
Configura para enviar o POST a cada 60 segundos para process.env.EXPO_PUBLIC_API_URL/ping.
Implementa o secret trigger no ecrã principal: 5 toques no AQI mudam a cor para vermelho temporariamente e fazem o log 'Status: Uplink established'

Entry Point:
Garante que o App.js na raiz apenas importa e renderiza o componente principal do /src e regista as tarefas necessárias
