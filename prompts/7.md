Melhora o dashboard atual para substituir o polling de 30 segundos por uma ligação Server-Sent Events que processe pings em tempo real de forma eficiente. Implementa a lógica para ouvir o stream HTTP e atualizar instantaneamente os marcadores no mapa e os contadores globais.
Cada novo evento deve inserir uma linha no topo da tabela com uma animação de slide suave e que o indicador "Ao vivo" pisque a branco momentaneamente para dar feedback visual imediato ao utilizador. O objetivo é transformar a interface atual num centro de comando fluido onde todos os elementos reagem.
